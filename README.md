# MyProject
## Library Management System

### Description
This is a console-based Library Management System developed in Python using Object-Oriented Programming (OOP).

### Features
- Add books
- Search books
- Issue books
- Return books
- Display available books
- Save records to a CSV file

### Classes

#### 1. Library
- Abstract base class
- Stores book title, ID, and author

#### 2. Book
- Inherits from Library
- Stores the book status
- Implements the display_details() method

#### 3. LibraryManagementSystem
- Manages all book records
- Handles searching, issuing, returning, and file operations

### OOP Concepts Used
- Abstraction
- Inheritance
- Encapsulation
- File Handling
- Exception Handling

### How to Run

```bash
python Library_System_Management.py
```
